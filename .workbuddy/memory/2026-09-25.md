## 第三次跑（00:18，同日第二次）：幂等正确 + 前台逻辑修复

主人跑的过程中把窗口切后台 → `AutoClaw 未在前台` pending。
根因：旧的 `Wait-Foreground` 只有一句 `SetForegroundWindow`，**用户在操作电脑时 Windows 会拒绝
非前台进程的切换请求**，45 秒轮询全废。这是无人值守场景的硬伤（主人一用电脑就漏签）。

修复（`scripts/ui_claim_autoclaw.ps1`）新增 `Ensure-Foreground`，逐级加码：
1. IsIconic → ShowWindow(SW_RESTORE)
2. **Alt 技巧**：keybd_event(0x12 按下) → SetForegroundWindow → keyup（Windows 通常放行）
3. **绑输入队列强切**：AttachThreadInput(当前线程, 目标窗口线程) → 切 → 解绑
4. 仍失败才轮询到 45s 超时

修完同一场景重跑：`今日已签到（．已完成已签到2天），无需重复点击` → **幂等正确，未重复点击**，
连签维持 2 天，台账不再入账。语法校验 errors=0。

**三次连跑可靠性初判**：9-24 already(手签过) / 9-25 ok(真签成功) / 9-25 再跑 already(幂等)
→ 幂等与重复跑均安全，**可以挂计划任务**了（勾「以最高权限运行」，静默提权不弹 UAC）。
