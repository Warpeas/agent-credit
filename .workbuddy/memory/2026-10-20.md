## 影子桌面 PoC 实测结论（23:06-23:46，CreateDesktop 后台签到可行性）

产物：`scripts/_poc_desktop.ps1`（parent/child 一体 -Child 开关）、
`scripts/_task_poc_desktop.ps1`（驱动，任务名 agent-credit-poc-once-20261020）、
`scripts/_poc_probe.ps1`（诊断探针）；日志 `logs/poc_desktop.log`，
实证截图 `logs/poc_client_printwindow.png`（Trae 完整 UI）。

**结论**：
- **后台识别（抓图+OCR+判据）完全可行**：CreateDesktop("agent-credit") +
  CreateProcessW(lpDesktop="WinSta0\agent-credit") 冷启动 → PrintWindow(PW_RENDERFULLCONTENT)
  抓到 Trae 完整 UI（359-587 色、std 22-35），WinRT OCR 出 60 词。用户屏幕零感知。
- **后台点击不可行**：影子桌面线程 SendInput → inserted=0，输入被系统直接拒绝
  （输入走「输入桌面」不跟调用线程桌面）。光标探针证明默认桌面光标纹丝不动——
  **机制上保证不会误点主人屏幕**（23:36 那轮的点击/打字同样被拒，未造成任何影响）。
  跨桌面只有 PostMessage/SendMessage 可达（WM_CLOSE/WM_GETTEXT 实测 OK），
  但 Chromium 自绘 UI 对合成鼠标消息无感，点不动签到按钮。
- 影子桌面上 BitBlt(GetDC(NULL)) 恒失败（全黑）→ MonkeyCode 的屏幕捕获路线不可用；
  冷启动窗口出现后 2-8s 才真正渲染（首帧 uniq=3）→ 捕获要重试到 uniq>5 && std>3。
- 推荐架构（待主人拍板）：客户端启动后 MoveWindow 移屏外 → OCR/判据全后台 →
  末次点击移回窗口（UIA Invoke 优先，坐标点击兜底：光标保存→瞬移→点击→复位 ~100ms）→ 关闭。

**工程坑（ps1 P/Invoke，全部实测，已修）**：
1. `CreateDesktopW` 的 lpszDevice 必须真 NULL：PS `$null` 字符串参数会被马谢成空串 →
   ERROR_INVALID_PARAMETER(87)。收 NULL 的字符串参数（lpszDevice/lpCurrentDirectory/
   FindWindowW 的 title）一律改 IntPtr 传 Zero。
2. `Marshal.SizeOf` 必须传结构体**实例**；传类型字面量 `[INPUT]` 会绑到 SizeOf(object)
   重载收到 RuntimeType，抛「不能作为非managed结构进行封送」。
3. 子进程要跑目标桌面：CreateProcessW(lpDesktop=...) **诞生在目标桌面**；
   SetThreadDesktop 从另起进程调用失败 ERROR_BUSY(170)。
4. WinRT OCR 前必须 `Add-Type -AssemblyName System.Runtime.WindowsRuntime`
   （漏了会在首个 Log 之前静默 exit 1，任务里看不到任何输出）。
5. `[uint]/[ushort]` 参数签名在任务上下文报 "Unable to find type" → 一律 [int]。
6. `$child` 与 `[switch]$Child` 大小写碰撞（PS 变量不区分大小写）→ 改名规避。
7. 任务结果 JSON 不删会导致轮询误判「已完成」——重跑前先删 result/child JSON。
